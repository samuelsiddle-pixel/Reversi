Small console application for the game Reversi (Variables and comments in Dutch)


Rules:

1. Starting position: The board starts with two red and two blue stones in the middle.
2. Taking turns: Players take turns placing one stone of their own colour on an empty square.
3. Valid moves: You can only place a stone if you enclose one or more opponent stones between your new stone and an existing stone of your own colour.
4. Directions: Enclosing can happen horizontally, vertically or diagonally.
5. Flipping stones: All opponent stones enclosed by your move change to your colour. Only stones directly enclosed by the newly placed stone are flipped.
6. Passing: If a player has no valid moves, they must pass their turn.
7. End of the game: The game ends when neither player can make a valid move.
8. Winner: The player with the most stones on the board wins. If both players have the same number, the result is a draw (remise).
9. 9. Size playing field: Can be changed to; 4x4, 6x6, 8x8 and 10x10.
